**簡単な答え:** **胖东来 (Pang Dong Lai, *Pàng Dōng Lái*)** は **河南省許昌** にあるスーパーマーケットチェーンで、中国で最も話題にされている雇用主となっています — 給与だけでなく、**996** や **牛马** を含む国では不可能に思えるパッケージのためです。

従業員は **年間40日の有給休暇**、**7時間の労働日**、すべての店舗が **火曜日** に閉店し、**10日の不开心假**（「不幸な休暇」）を取得できます。この不开心假は、単に働きたくないからという理由で取得でき、**マネージャーは拒否することができません**。2025年の平均手取り給与は **¥8,974/月**、2026年初頭には **¥9,598** でした。顧客に虐待された従業員は、最大 **¥5,000** の **委屈奖**（「不満賞」）を請求できます。

そして、全体の話を奇妙にする詳細があります：**2026年2月**、会社は従業員に給与の一部を休暇と交換することについて調査を行いました。**82.38%が「いいえ」と答え** — 彼らは現状のままでいてほしいと望んでいました。

## 特に利点

| | |
|---|---|
| **年間休暇** | 40日有給 |
| **「不幸な休暇」(不开心假)** | 10日、従業員の裁量で取得可能；マネージャーは拒否できない |
| **労働日** | 約7時間、残業文化なし |
| **週の閉店** | すべての店舗が火曜日に閉店 |
| **平均手取り給与** | ¥8,974/月（2025年）；¥9,598/月（2026年1月〜3月） |
| **不満賞 (委屈奖)** | 顧客に不当な扱いを受けた従業員に最大¥5,000 |
| **従業員数** | 10,000人以上の正式契約従業員 |
| **2024年の売上** | 約¥170億 |

休暇の数字についての背景：典型的な中国企業は約 **5日** の法定年間休暇を提供します。胖东来は **40日** を提供しています。

## 不开心假 — 誰もが話題にするもの

**不开心假** (*bù kāi xīn jià*) は、その響き通りに分解できます：不开心 = "不幸"、假 = "休暇"。

年間10日、気分が乗らないから取得します。医者の診断書も説明も必要ありません。

重要なのは、その実施です。創業者 **于东来 (Yu Donglai)** は公に **管理者はリクエストを拒否できない — 拒否すること自体が違反である** と述べました。その逆転が、装飾的ではなく実際のものにしています。ほとんどの「無制限の休暇」ポリシーは、承認が裁量に依存し、誰もが頼むことを望まないため失敗します。ここでは、拒否することが罰せられる行為です。

それに加えて **委屈奖** (*wěi qu jiǎng*)、つまり「不満賞」があります。委屈は正確で非常に中国的な言葉 — 不当な扱いを受けたと感じ、それを飲み込まなければならない感情です。小売業の従業員はそれを日々吸収しています。胖东来は最大¥5,000を支払い、業界全体が依存している「顧客は常に正しい」という前提を静かに覆します。

## 物語を面白くする投票

ここからは特典のリストではなくなります。

**2026年2月23日から24日**の間に、会社は **10,214** 人の正式契約従業員に **給与を減らしてより多くの休暇を得る提案** について調査を行いました。**9,686** 件の有効な回答が返ってきました。

**82.38% — 7,979人 — が現状を維持することに投票しました。** そして **97.55%** が現在の40日間の取り決めに満足または非常に満足していると答えました。

これを注意深く読んでください。これは簡単な物語に反するものです。これは、休暇を求めていた労働力ではありません。彼らは *より多くのものを提供され*、答えています：**私たちは大丈夫です。** 40日と7時間の労働日は、どうやら中国の小売業者が時間を求めるのをやめ、お金を求め始めるポイントのようです。

## なぜこれが反内卷の会社なのか

中国の人々がこのスーパーマーケットについて話す理由を理解するには、それが反論となる語彙が必要です。

- **[内卷](/slang/nei-juan)** (*nèi juǎn*)、"内巻" — 努力を増やしても報酬が増えない競争。誰もがより一生懸命働き、誰もが前に進まない。
- **[996](/slang/996)** — 午前9時から午後9時まで、週6日。国の議論となった技術業界のスケジュール。
- **[牛马](/slang/niu-ma)** (*niú mǎ*)、"牛と馬" — 労働者が自分たちを呼ぶ言葉：人間性のない労働。
- **[打工人](/slang/da-gong-ren)** (*dǎ gōng rén*)、"賃金労働者" — 普通の従業員の皮肉で疲れた自己ラベル。

そして、システムが変わらないときに人々が選んだ出口：

- **[躺平](/slang/tang-ping)** (*tǎng píng*)、"横たわる" — オプトアウトし、最小限のことをする。 ([完全な説明 →](/blog/tang-ping-lying-flat-chinese-millennial-movement-meaning))
- **[摆烂](/slang/bai-lan)** (*bǎi làn*)、"腐らせる" — 意図的に状況を改善することをあきらめる。

躺平と摆烂は、内卷に出口がないときに得られるものです。胖东来の重要性は、単に良い給与を支払い、早く終わる雇用主を提案することです。そして、それを行いながら非常に利益を上げています。だからこそ、中国の議論においては、会社として機能するのではなく、**議論**として機能します — 996/牛马の取引が経済法則ではなく選択であることの証拠です。

## 経済学、特典は慈善ではない

明らかな反論は、これは意図的に損失を出している場合にのみ機能するということです。胖东来はそうではありません。

**于东来** は中学校を中退し、**1990年** にタバコ店を始め、**1995年** に小さな小売店を開きました。2024年までに、ビジネスは年間 **¥170億** に近い売上を上げていました。

モデルにはいくつかの意図的なレバーがあります：

- **限られたマージン。** 迅速に動く消費財の利益は約 **30%** に制限されており、通常、棚の配置のために供給者が支払う「舞台裏の手数料」は排除されています。
- **自社ブランドの深さ。** 売上の約 **30%** は、工場や農場と直接開発した自社の **DL** ブランドから来ており、卸売業者を排除しています。
- **信頼を製品とする。** **2024年6月**、供給者で衛生問題を発見した後、会社は **内部告発者に¥100,000を支払い**、**影響を受けた顧客に¥1,000を返金** しました — 中国の小売業の基準からはるかに外れた反応で、全国ニュースになりました。食品安全に対する慢性的な不信感がある市場では、その評判が防御線となります。

スタッフポリシーはこれとは切り離せません。小売の質は人によって提供され、休息を取り、十分に支払われ、絶望していない人々がそれをより良く提供します。特典は *戦略* です。

## ハローを複雑にする部分

このテンプレートとして扱う前に知っておくべき2つのことがあります。

**一人の会社です。** **2026年8月**、于东来はライブストリームで、**24年間**営業しており、上半期の売上がほぼ **¥10億**、年間で **¥20億** を見込んでいる **許昌ライフプラザ店** を **年末に閉店する** と発表しました。そのような決定は、ピークの利益率で行われ、ライブストリームで発表されると、モデルが創業者の個人的な判断から切り離せないことを示しています。これは誰もが模倣できるガバナンス構造ではありません。

**一つの都市です。** 胖东来は河南省の中規模都市である許昌で運営されており、地元の賃金水準と地元の家賃があります。同じ算術が上海や深圳で生き残るかどうかは本当に証明されていません — そしてモデルの支持者と批評家は、まさにその点について2年間議論しています。

これらのことは、82%の投票が特別であることを否定するものではありません。ただ、正直な読み方は：*これは本物の反例であり、設計図ではない* ということです。

## よくある質問

**胖东来とは何ですか？**
許昌、河南省に本社を置くスーパーマーケットチェーンで、従業員の待遇と顧客サービスで全国的に有名です。

**不开心假とは何ですか？**
「不幸な休暇」 — 従業員が単に働きたくないから取得できる年間10日間の休暇。マネージャーは拒否できません。

**胖东来の従業員はどれくらいの年間休暇を取得しますか？**
40日有給で、典型的な中国企業の約5日と比較されます。

**胖东来の従業員はどれくらい稼ぎますか？**
2025年の平均手取り給与は¥8,974/月、2026年初頭には¥9,598/月でした。

**従業員は本当にさらなる休暇を拒否しましたか？**
はい。2026年2月に10,000人以上のスタッフを対象にした調査で、82.38%が現在の給与と休暇を維持することに投票しました。

**委屈奖とは何ですか？**
顧客から不当な扱いを受けた従業員に最大¥5,000の「不満賞」です。

**胖东来は利益を上げていますか？**
はい — 2024年の売上は約¥170億で、限られたマージンと大規模な自社ブランドの範囲を持っています。

**他の会社はこれを模倣できますか？**
不明です。これは一人の創業者の個人的な決定と一つの中規模都市のコスト基盤に密接に結びついています。
